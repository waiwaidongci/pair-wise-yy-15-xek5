# 离线赛鸽训放坐标核验台

面向赛鸽棚的**纯离线**训放记录与坐标核验工具（React + Vite + TypeScript）。数据只存浏览器 localStorage，无需后端。

## 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | **规则层**：纯函数。坐标核验（缺失 / 时间倒置 / 距离偏差 > 5%）、训放点按「鸽棚 + 坐标」去重、Haversine 实测距离、排行、未归巢提醒、配对候选、两人复测确认 |
| `src/archive.ts` | **档案层**：localStorage 持久化、训放登记、坐标/时刻更正、旧结果快照、复测确认、示例数据 |
| `src/App.tsx` | **界面层**：鸽棚总览、训放登记、成绩排行、未归巢提醒、配对候选、待复核、单羽档案、旧结果八个视图 |

## 业务规则

1. **训放点唯一**：按「鸽棚 + 坐标」唯一，重复坐标只留首次建档，后续登记复用该训放点。
2. **登记内容**：足环号、血统、放飞/归巢时刻、训放点坐标、登记距离、天气。
3. **只进待复核**（不计排行、未归巢提醒、配对候选）：
   - 坐标缺失；
   - 时间倒置（归巢早于放飞）；
   - 登记距离与「棚坐标 → 训放点」Haversine 实测距离偏差超过 5%。
4. **更正流程**：更正坐标或时刻时自动冻结一份旧结果快照（旧结果可查），该记录随即失效并进入「待复测确认」；必须**两名不同复核人**复测确认后才恢复，恢复后排行 / 提醒 / 配对候选 / 血统筛选统一重算。若复测完成但数据仍不合格，记录留在待复核区。
5. **状态一致**：所有视图都从同一份档案 + 同一套规则派生（`getResults` 单一入口），刷新页面后从 localStorage 恢复，各处状态一致。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:62014
```

其他命令：

```bash
npm run build        # 生产构建
npm run check:rules  # 端到端规则校验（30 项断言）
```

首次打开自动灌入示例数据（含合格记录、未归巢、坐标缺失、时间倒置、距离超标各场景）；顶栏可一键恢复示例或清空档案。
