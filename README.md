# hxyfront-62014 赛鸽训放坐标核验台

离线（无后端，localStorage 存档）的赛鸽训放坐标核验工具。规则、档案、界面严格分属三个业务文件。

## 业务文件划分

| 文件 | 职责 |
| --- | --- |
| `src/business/rules.ts` | **规则**（纯函数，无存储/DOM）：训放点按「鸽棚+坐标」唯一、首次登记定基准、坐标/时间/距离核验、排行、未归巢提醒、配对候选、血统筛选所需的统一派生状态 |
| `src/business/archive.ts` | **档案**：localStorage 持久化、登记去重（重复只留首次）、更正冻结、旧结果快照、两人复测确认恢复 |
| `src/business/console.tsx` | **界面**：总览 / 登记 / 排行 / 提醒 / 待复核 / 复测 / 档案 / 旧结果留档八个视图 |

## 核验规则

1. **训放点唯一**：以「鸽棚 + 经纬度（6 位小数）」为键，重复登记只保留首次；首次距离作为该点基准距离。
2. **进待复核（不计排行 / 未归巢提醒 / 配对候选 / 血统历史）**：
   - 坐标缺失或经纬度非法；
   - 时间倒置：归巢早于放飞，或放飞早于同点首次放飞时刻；
   - 登记距离与基准距离偏差 **> 5%**（恰好 5% 放行）。
3. **更正工作流**：更正坐标 / 时刻 / 距离后，原排行、提醒、血统筛选立即失效并按新值重算；记录进入「复测冻结」，更正前完整结果存入「旧结果留档」可随时查阅。
4. **两人复测**：需两位复测人签署（不得与更正人同一人、不可重复签署）；第 2 人确认时重新核验——无问题恢复计入，仍有问题回到待复核。
5. **刷新一致**：所有视图由同一份 `deriveAll(records)` 派生，存档落 localStorage，刷新 / 重开后从同一存档重算，各处状态一致。

登记字段：足环号、血统、鸽棚、纬度、经度、放飞时刻、归巢时刻、距离、天气、健康备注。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62014
npm run build    # 类型检查 + 生产构建
```

首次打开自动生成覆盖各种核验情形的示例档案，可在右上角「重置示例数据」还原。
